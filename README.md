# Fix My Laggg

A tongue-in-cheek Minecraft mod that doesn't actually improve your FPS — it just makes it *look* like it does.

## Features

- **Configurable Fake FPS** — set your desired displayed FPS anywhere from 1 to 12,000
- **Realistic Sink** — fake FPS dips proportionally when real FPS drops, so the illusion holds up under scrutiny
- **Universal Spoofing** — fake values show up everywhere FPS is normally read, including Minecraft's F3 debug screen and third-party overlays like Feather Client
